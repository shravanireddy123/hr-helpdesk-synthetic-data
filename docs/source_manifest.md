# Source manifest

This file records where every part of the dataset comes from. The repository contains no real personal data.

| Item | Source | Licence / note |
|---|---|---|
| All records | Generated by `python -m hrgen` | Synthetic; no real people or companies |
| Names | Faker (`en_IN` locale), seeded with 20261022 | MIT |
| Emails | Built from fake names with the domain `hrdemo.example` | Reserved example domain; not real |
| Randomness | Python `random.Random(20261022)` | Standard library |
| Policy titles and rule values | Written by hand in `hrgen/master_data.py` | Fictional; not real company policy |
| Holiday list | Fixed company list in `hrgen/business_calendar.py` | A design choice, not an official calendar |
| Message text | Templates in `hrgen/messages.py` and `hrgen/tickets.py` | Written for this project |
| External datasets | None | No downloads, no scraping, no APIs |
